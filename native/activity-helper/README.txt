Apochill 작업 연결 도우미 1.0.0 · Windows 10/11

1. ZIP 파일의 압축을 풀어 주세요.
2. Apochill Helper.exe를 더블클릭하세요. Node.js나 개발 서버는 필요 없습니다.
3. https://apochill.lastweek.chatgpt.site/ 에서 ‘작업 상태 · PC 연결’을 열어 주세요.
4. ‘도우미 실행했어요 · 연결하기’를 누르고 브라우저가 이 PC에 연결할 권한을 물으면 허용하세요.

창을 닫으면 작업 표시줄의 숨겨진 아이콘에서 계속 실행됩니다.
완전히 끄려면 도우미 창 또는 아이콘 메뉴에서 ‘종료’를 누르세요.
사이트의 ‘앱 감지 끄고 직접 선택’으로 수동 상태로 돌아갈 수 있습니다.
사이트와 2분간 통신하지 않으면 앱 감지를 멈춥니다.
시작프로그램을 등록하거나 관리자 권한을 요청하지 않습니다.

허용된 앱의 실행 파일 이름만 이 PC 안에서 전달합니다.
창 제목, 문서/채팅 내용, 키 입력은 읽거나 저장하지 않습니다.
외부 서버에 감지 결과를 전송하지 않습니다.
지원 앱: ChatGPT, Codex, Notion, Blender, Unreal Engine, Photoshop,
CapCut, VS Code, Figma, Chrome, Edge, Firefox.
브라우저의 탭 내용은 감지하지 않습니다.

이 실행 파일은 아직 코드 서명이 없어 Windows가 게시자를 확인할 수 없다고 표시할 수 있습니다.
보안 설정을 끄지 마세요. 실행하지 않고 사이트의 수동 상태 선택을 이용할 수도 있습니다.
실행이 차단된 관리 PC에서는 조직 관리자에게 문의하세요.

기존 Node.js 도우미가 실행 중이면 종료한 뒤 이 도우미를 실행하세요.
연결이 안 되면 브라우저의 로컬/루프백 연결 권한과 도우미 실행 여부를 확인하세요.
